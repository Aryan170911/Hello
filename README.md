# Click the square

A tiny browser game: click the blue square, it jumps, your score goes up.

Open `index.html` in a browser. That is the whole game.

## How Cursor helped

I built this in [Cursor](https://cursor.com) by asking for the simplest HTML game.

Cursor:

- Wrote a single `index.html` file (HTML, CSS, and a few lines of JavaScript)
- Opened the game in the browser and actually clicked it
- Fixed contrast when the page rendered too dark to read the score
- Kept the square inside a play area so it could not jump off-screen
- Created the git branch and commit for this work

I did not set up a framework, a bundler, or extra files. Cursor shipped the smallest thing that played.
